# country-of-geniuses

Solas Agent Mesh demo of a coordinated 1,000-agent topology:

- 1 orchestrator (persistent)
- 10 heads (persistent)
- 100 managers (dynamic + discovery surface)
- 889 citizens (dynamic + manager-simulated by default)

## Project Structure

- `src/`: runtime services (`micro_a2a_service.py`, topology model, launcher)
- `scripts/`: generation + run/stop scripts
- `configs/`: SAM agent/service/gateway configs
- `static/`: hierarchy map UI

## Quick Start

1. Create a Python virtual environment and install dependencies:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
2. Create local environment config:
   ```bash
   cp .env.example .env
   ```
3. Fill `.env` with your broker + LLM values.
4. Start the stack:
   ```bash
   bash scripts/run_solasland_hierarchy.sh
   ```

## Health Endpoints

- Web UI / gateway: `http://127.0.0.1:8000/health`
- micro-A2A: `http://127.0.0.1:9100/health`

## Stop

- Stop SAM only:
  ```bash
  bash scripts/stop_solasland.sh sam
  ```
- Stop SAM + micro-A2A:
  ```bash
  bash scripts/stop_solasland.sh all
  ```

## Regeneration

Hierarchy/proxy artifacts are regenerated by startup scripts, or manually:

```bash
python3 scripts/generate_hierarchy.py
python3 scripts/generate_agent_registry.py
```
